# The Challenge and Reward of Fair Play in Narrative: A Computational Approach

Code for the paper:

> **The Challenge and Reward of Fair Play in Narrative: A Computational Approach**
> Eitan Wagner, Renana Keydar, Omri Abend
> Hebrew University of Jerusalem
> *Preprint, 2026*

We formalize the tension between *surprise* and *coherence* in detective fiction using an information-theoretic framework that models readers as probabilistic agents performing sequential belief updating. We operationalize this framework using LLMs as simulated readers — from a gullible reader susceptible to misdirection to an experienced reader with prior-story context. Experiments on stories generated by 10+ LLMs and validated by human readers show that fair play (combining high surprise and coherence) is a genuine challenge even for frontier models, and does not scale monotonically with model capability.

```

├── crime_fiction.py        # Story generation and LLM reader evaluation
```

## System requirements

- **Python**: 3.11+ (tested on 3.11)
- **OS**: Tested on Debian 12
- **Hardware**: No non-standard hardware required. Story generation and reader estimation require API access (see below); analysis of pre-generated data runs on any standard desktop.
- **Dependencies**: Listed in `requirements.txt`

## Setup

**1. Clone and install dependencies**

```bash
git clone <repo-url>
cd detective-stories-public
pip install -r requirements.txt
```

Typical install time: under 5 minutes on a standard desktop (excluding PyTorch, which may vary).

**2. Set API credentials**

Copy `.env.example` to `.env` and fill in your API keys:

```bash
cp .env.example .env
# edit .env with your keys
```

Then load them before running (or use `python-dotenv`):

```bash
export $(grep -v '^#' .env | xargs)
```

Required keys depend on which models you use:
- `OPENAI_API_KEY` — GPT-4o, GPT-4o-mini, o-series models
- `GOOGLE_API_KEY` — Gemini models
- `GOOGLE_APPLICATION_CREDENTIALS`, `GOOGLE_CLOUD_PROJECT` — Vertex AI (Llama models via Google Cloud)

## Reproducing the analysis

All analyses and figures in the paper can be reproduced from the pre-generated story files in `stories/` and human study results in `results/`.

```bash
cd analyze_results
python main.py
```

Output figures are saved to `plots/` (PNG and PDF). Toggle individual analyses at the top of `main.py` via the `RUN_*` flags.

Expected run time: under 5 minutes on a standard desktop for the full analysis pipeline from pre-generated data.

## Generating new stories

Stories are generated paragraph by paragraph (25 paragraphs per story). At each step the model receives the story so far and is prompted to write the next paragraph, given the suspect list, true culprit, and distractor (see SI Appendix §7 for the exact prompts).

```bash
python crime_fiction.py -mt openai -mn gpt-4o -md -np 25
```

Key arguments (see `utils.py` for the full list):

| Argument | Description |
|---|---|
| `-mt` | Model type: `openai`, `gemini`, `llama` |
| `-mn` | Model name (e.g. `gpt-4o`, `gemini-2.5-pro`, `Llama-3.3-70B-Instruct`) |
| `-md` | Generate stories |
| `-ld` | Load existing stories for evaluation |
| `-np` | Number of paragraphs per story (25 in the paper) |
| `--id` | Story index (for parallelising across stories) |

Generated stories are saved as JSON to `stories/`.

## Estimating reader models

**Gullible reader** (simulated naïve reader, the main surprise metric):

```bash
python crime_fiction.py -mt openai -mn gpt-4o -ld -st gpt-4o -es2
```

**Know-it-all reader** (sampling-based upper bound on coherence, `nsamp=20`):

```bash
python crime_fiction.py -mt openai -mn gpt-4o -ld -st gpt-4o -es3
```

**Experienced reader** (with *k* previous stories from the same model):

```bash
python crime_fiction.py -mt gemini -mn gemini-3-flash-preview -ld -st gpt-4o -es3
```

After evaluation, run:

```bash
python get_stats.py  # extract culprit paragraph, character names, etc.
```

## Models used in the paper

| Family | Models |
|---|---|
| Gemini | Gemini 1.5 Pro, Gemini 1.5 Flash, Gemini 2.5 Flash (TB0, TB-1), Gemini 2.5 Pro, Gemini 3 Flash, Gemini 3.1 Pro |
| GPT | GPT-4o, GPT-4o-mini |

Real-story baselines: **Sherlock Holmes** (*The Adventures of Sherlock Holmes*) and **Hercule Poirot** (*Poirot Investigates*), sourced from Project Gutenberg.

## Data

- **Generated stories**: `stories/` — JSON files per model, naming convention `{model}_w_suspects_sbs_d25_w_details2.json`
- **Human study data**: `results/for eval2/` — Excel file with crowdsourced suspect predictions and subjective ratings (n=20 participants)
- **Classic baselines**: `stories/sherlock_w_suspects*.json`, `stories/poirot_w_suspects*.json`
- **Project Gutenberg source texts**: not included; see `extract_stories.py` and set `DETECTIVE_FICTION_CSV` / `DETECTIVE_BOOKS_JSON` env vars (see `.env.example`)
